# Chat interaction contract

Existing authenticated APIs, native request keys, upload contract and decisions are unchanged.

Enter submits once, Shift+Enter creates a line, composition Enter does not submit. Empty/whitespace sends are ignored unless files/source selections exist. Pasted/dropped files use the same max-five/10MiB-per-file parsing and native fallback as the picker, and disabled intake cannot mutate the draft. Busy ordinary chat permits a new correction; Stop posts through the existing governed native cancellation route. Ambiguous outcomes are never automatically resent.

Viewport honors user scroll intent, handles late content/layout changes, restores per-conversation numeric position and exposes Scroll to bottom. Storage errors are nonfatal. Reduced motion avoids animated jumps. Denied/source-stale content remains cleared.

Tools and authorization derive only from the current authorized native SDK projection. Saved prose keeps its exact canonical content and identity; supplemental activity never becomes execution state. Question/approval replies use existing request IDs and explicit action review. Suppress thinking while user input or authorization is pending and after errors. Preserve explicit cancellation, unknown/deadline and failure notices; ordinary success needs no permanent operational footer.

# Guidance contract

- search_evidence defaults to current_fact. accepted_fact and discovery are explicit
  historical/investigative choices, never an automatic fallback after fresh search fails.
- Public-reference retrieval receives that same mode. Current mode excludes expired
  or invalid snapshots before ranking and rechecks at disclosure; history keeps dates.
- The seven-day boundary uses original evidence age; earlier explicit review/cache
  deadlines win. Current live documentation may be observed today without rewriting
  its publication date. Shared guidance inherits its supporting originals' deadline.
- Empty/insufficient current support directs Turi through prepare_customer_research,
  matching specialist, then the correct result reader. Do this without another user
  permission question. A returned reservation is not completed research.
- Default refresh=false allows existing recent checked results and in-progress work
  to be reused. Never force repeated searches because an unchanged old source exists.
  Explicit user challenges/refinements retain their existing refresh=true semantics.
- Missing scope, unavailable/denied work and no newer evidence are explicit outcomes.
  Private facts need internal updates. No automatic sharing, acceptance or publication.
- Existing budgets, cancellation, grants, conflict and source-withdrawal fences remain.

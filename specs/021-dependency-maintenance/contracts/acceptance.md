# Acceptance contracts

- Malformed MCP bearer: generic401, zero DB calls. Valid syntax still requires persisted scope/expiry/revocation checks.
- Interrupted generation/stream: preserve result/event; no settlement or external-fee completion. Completed positive controls settle once through existing service.
- Artifact consumer: immutable action pin, digest-mismatch error, current attempt pattern, separate project directories, successful producers and complete four-project inventory.
- Hosted release: exact source, schema85, existing accounts and isolated protected Preview; Production identity/behavior separately verified.
- Cleanup: no lost unique source, archive, key, budget or financial hold; originals retire only with explicit delivery/disposition evidence.

## T001 framework and baseline review

The installed dependency manifest selects eve 0.67.x, Next.js 16.3.4, React 19.2.6, TypeScript 7.0.2, PostgreSQL 17, Zod 4.5.4 and pg 8.23.0. The local shell currently runs Node 26.8.2; the project target is Node 24, so any behavior verified on this shell needs a Node 24 check before claiming the feature validated.

Read the installed eve docs index and the routed instructions, dynamic-capabilities, tools and hooks pages. `defineDynamic` user-role instructions can load at `turn.started`; `step.started` hooks can fail a turn before the next model call. Hooks are observe-only and cannot edit native history. Read the installed Next.js App Router route-handler guide: `app/**/route.ts` handles request methods; GET handlers are uncached by default. Preserve the selected model in `agent/agent.ts` and the current package lock.

Baseline: 002 provides synthetic identities, partner grants, private owned conversations, guarded eve dispatch and durable native state. It has no accepted profile facts, review lifecycle, source quality, or 003 context fence. The required check matrix is schema/quality unit tests; disposable migration, race and recovery tests; HTTP/tool/stream contract tests; four CLI WebKit viewport/theme projects; synthetic benchmark; opt-in live evaluation; and five-person usability walkthrough. These are targets, not passed results.

Use only the bound learning context and its original citation keys. User feedback
is an unverified observation, never an accepted fact or permission to reuse data.
Read only learning_summary and learning_evidence when necessary. Preserve unknowns.
Draft one sanitized practice: remove customer names, domains, repositories, people,
commercial details and identifying configurations or combinations of outcomes.
Do not invent evidence, approve rights, accept a candidate, publish, train models,
change instructions, send messages or use another customer's information.
Return the strict learning-v1 proposal, selected citationKeys, explicit unknowns
and intendedImprovement. Human review and publication remain separate decisions.
